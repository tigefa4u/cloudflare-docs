<Description>

Progressive Worker rollouts with automatic health checks, built on Workflows.

</Description>

Health-mediated deployments (HMD) let you roll out a new Worker version in percentage steps — pausing at each step to check error rates before continuing. If a health check fails, the rollout pauses or rolls back automatically.

HMD is built on [Workflows](/workflows/). Each rollout is a durable Workflow instance that carries the deployment through its steps, waits for soak times, checks observability signals, and promotes or reverts the version based on the result.

Two modes are available:

- **Simple case** — add `hmd.plan: "cloudflare/default"` to your `cloudflare.config.ts`. Cloudflare manages the rollout plan with sensible defaults for percentages, soak times, and error thresholds.
- **BYO Workflow** — write a `cloudflare.hmd.ts` file that extends `HMDWorkflow`. Define your own rollout percentages, health queries, soak times, and Flagship flag changes.
