<Description>

Define your entire CI pipeline in TypeScript. Run it on Cloudflare.

</Description>

CI on Workflows lets you replace external CI providers with a pipeline defined in `cloudflare.ci.ts`. Your pipeline runs as a [Workflow](/workflows/) triggered by a push to an [Artifacts](/artifacts/) repository. You declare the trigger in `cloudflare.config.ts` — no webhooks or external glue to wire up.

A CI pipeline is just a Workflow. The `CIWorkflow` class extends `WorkflowEntrypoint` with primitives for dependency caching, parallel step execution, and release tasks. Because the pipeline is a Workflow, you get durable execution, automatic retries, and built-in observability at no extra cost.

Use CI on Workflows when you need to:

- Run lint, build, typecheck, test, and format in parallel from a single cached dependency snapshot
- Deploy one Worker or many Workers across environments from the same pipeline run
- Skip the pipeline entirely when dependencies have not changed
- Integrate health-mediated deployments directly into your release step
